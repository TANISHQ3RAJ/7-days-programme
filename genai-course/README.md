# GenAI Academy 🚀

Welcome to the **GenAI Academy**! This is a premium, interactive landing page for a 7-day intensive program designed to help you master Artificial Intelligence, Prompt Engineering, Context Engineering, and multi-agent systems.

## 🚀 Live Demo

**Check out the live deployment here:** [https://genai-contextengineering.netlify.app/](https://genai-contextengineering.netlify.app/)

## ✨ Features

- **Modern & Interactive UI**: Built with a stunning, futuristic dark theme using Tailwind CSS and Framer Motion.
- **7-Day Curriculum Tracker**: Interactive day-by-day curriculum highlighting topics like:
  - Introduction to GenAI
  - Prompt Engineering
  - Context Engineering
  - AI Tools Ecosystem
  - Automation & Agents
  - Building Real Projects
  - Future of AI
- **Responsive Design**: Flawless experience across all devices.
- **Enrollment Flow**: Built-in modal for user registration and lead capture.

## 🛠️ Technology Stack

- **Frontend Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/) (TypeScript)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository** (if you haven't already).
2. **Navigate to the project directory**:
   ```bash
   cd genai-course
   ```
3. **Install the dependencies**:
   ```bash
   npm install
   ```
4. **Start the development server**:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to the local URL provided by Vite (usually `http://localhost:5173`).
