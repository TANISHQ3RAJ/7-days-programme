# GenAI & Context Engineering: 7-Day Intensive Curriculum

## OVERVIEW
This 7-Day Course is designed for college students, beginners, developers, entrepreneurs, and creators. It progresses from beginner concepts to advanced context engineering and AI automation, ending with a capstone project.

**Format per Day:** 1.5-Hour Live Lecture (plus assignments)
**Total Course Time:** 10.5 Hours Live + 10 Hours Practical

---

## DAY 1: Introduction to Generative AI
**Topic:** The Dawn of Intelligent Systems
**Learning Objective:** Understand the fundamentals of AI, ML, LLMs, and Generative AI, and their real-world impact.
**Free Tools Used:** ChatGPT Free, Claude Free

### 1.5-Hour Breakdown
- **15 min → Introduction:** Welcome, course roadmap, and what to expect.
- **25 min → Core Concepts:** What is AI vs ML vs Deep Learning vs GenAI? The Evolution of AI.
- **20 min → Tool Demonstration:** Live demo of ChatGPT & Claude capabilities (Text, Reasoning, Code).
- **20 min → Hands-on Practice:** Setting up accounts, writing first conversational prompts.
- **10 min → Q&A:** Open floor for student queries.

**Mini Project:** "AI Origin Story" - Use GenAI to explain how AI evolved, tailored for a 5-year-old.
**Homework:** Research and list 3 real-world applications of Ethical AI.

---

## DAY 2: Prompt Engineering Fundamentals
**Topic:** Speaking the Language of AI
**Learning Objective:** Master the anatomy of a prompt and advanced prompting techniques.
**Free Tools Used:** ChatGPT, Gemini

### 1.5-Hour Breakdown
- **15 min → Introduction:** Why Prompt Engineering is the new coding.
- **25 min → Core Concepts:** Anatomy of a prompt. Zero-shot, One-shot, Few-shot prompting.
- **20 min → Tool Demonstration:** Applying Chain-of-Thought and Structured Prompting.
- **20 min → Hands-on Practice:** Iteratively refining a poorly written prompt into a high-quality prompt.
- **10 min → Q&A:** Troubleshooting prompt failures.

**Mini Project:** "The Expert Consultant" - Write a structured prompt that turns ChatGPT into a specialized consultant.
**Homework:** Complete the "10 Prompt Variations" worksheet.

---

## DAY 3: Context Engineering (MAIN HIGHLIGHT)
**Topic:** Architecting AI Memory & Systems
**Learning Objective:** Move beyond basic prompting to understanding context windows, memory, and RAG basics.
**Free Tools Used:** NotebookLM, Claude

### 1.5-Hour Breakdown
- **15 min → Introduction:** What is Context Engineering? Why prompts aren't enough.
- **25 min → Core Concepts:** Context windows, Token optimization, System prompts, Memory systems, basics of Retrieval-Augmented Generation (RAG).
- **20 min → Tool Demonstration:** Using Google NotebookLM to interact with custom document context.
- **20 min → Hands-on Practice:** Crafting a comprehensive System Prompt for AI personalization.
- **10 min → Q&A:** Addressing context limits and token management.

**Mini Project:** "Personal Knowledge Base" - Upload 3 documents to NotebookLM and extract a structured report.
**Homework:** Design a system prompt architecture for a specific persona.

---

## DAY 4: AI Tools Ecosystem
**Topic:** The Modern AI Arsenal
**Learning Objective:** Navigate and utilize the top free AI tools for text, images, and productivity.
**Free Tools Used:** Perplexity, Gamma, Canva AI, Leonardo AI, Hugging Face, OpenRouter, Groq

### 1.5-Hour Breakdown
- **15 min → Introduction:** Overview of the AI Tool Landscape (Text vs Visual vs Workflow).
- **25 min → Core Concepts:** Comparing models (GPT vs Claude vs Gemini vs Llama).
- **20 min → Tool Demonstration:** Rapid-fire demos: Perplexity for research, Gamma for slides, Leonardo AI for images.
- **20 min → Hands-on Practice:** Creating a multi-modal presentation using at least 3 different tools.
- **10 min → Q&A:** Discussion on which tools are best for specific use cases.

**Mini Project:** "AI Multi-Tool Pipeline" - Research a topic with Perplexity, write content with Claude, create slides with Gamma.
**Homework:** Explore Hugging Face Spaces and try one open-source model.

---

## DAY 5: AI Automation & Agents
**Topic:** Building Systems That Work While You Sleep
**Learning Objective:** Understand multi-agent systems, AI workflows, and no-code automation.
**Free Tools Used:** n8n, Flowise (or Langflow local/free tier)

### 1.5-Hour Breakdown
- **15 min → Introduction:** What are AI Agents and Copilots?
- **25 min → Core Concepts:** Agentic workflows, Multi-agent systems, No-code AI pipelines.
- **20 min → Tool Demonstration:** Building a simple automated pipeline (e.g., extracting data and sending an email) using n8n.
- **20 min → Hands-on Practice:** Setting up a basic visual node flow in Flowise or Langflow.
- **10 min → Q&A:** Debugging agents and automation logic.

**Mini Project:** "My First AI Assistant" - Build a simple multi-step workflow.
**Homework:** Map out an automation workflow for a daily mundane task.

---

## DAY 6: Building Real Projects
**Topic:** From Theory to Product
**Learning Objective:** Apply learned skills to build practical, beginner-friendly AI projects.
**Free Tools Used:** Combination of tools from previous days.

### 1.5-Hour Breakdown
- **15 min → Introduction:** How to frame and scope an AI project.
- **25 min → Core Concepts:** Walkthrough of architecture for 5 project types (Resume Builder, Study Assistant, Content Creator, Chatbot, Research Assistant).
- **20 min → Tool Demonstration:** Live build of the "AI Study Assistant" using customized system prompts and context.
- **20 min → Hands-on Practice:** Students choose one of the 5 projects and begin scaffolding their implementation.
- **10 min → Q&A:** Feedback on project scopes.

**Mini Project:** "Project Prototype" - Complete the initial build of the chosen project.
**Homework:** Refine and finalize the project for presentation.

---

## DAY 7: Future of AI + Final Capstone
**Topic:** Your AI-Powered Career
**Learning Objective:** Discuss AGI, future careers, monetization, and present capstone projects.
**Free Tools Used:** Presentation tools.

### 1.5-Hour Breakdown
- **15 min → Introduction:** The Road to AGI and the future of work.
- **25 min → Core Concepts:** AI careers, Freelancing, Startup ideas, and Monetization strategies.
- **20 min → Capstone Presentations:** Volunteer students present their Day 6 projects.
- **20 min → Career Roadmap:** LinkedIn optimization, portfolio building, and internship guidance.
- **10 min → Wrap-up & Certification Ceremony:** Distributing certificates and explaining the Discord community.

**Mini Project:** "The AI Portfolio" - Add the completed project to a portfolio or GitHub.
**Homework:** Update LinkedIn profile with new AI skills. Join the community.
